# LeetCode - TypeScript Solutions

Personal solutions to LeetCode problems, written in TypeScript with detailed comments explaining the approach and complexity.

## Structure

Each solution includes:
- Problem statement summary
- Approach and key insight
- Time and space complexity
- Inline comments throughout the code

## Run locally

```bash
npx ts-node filename.ts
```

## Notes

Solutions focus on clarity over brevity. The goal is to understand the pattern, not just pass the test.
